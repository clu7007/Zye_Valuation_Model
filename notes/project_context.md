# 台股財報自動化工具 — 專案背景

> 每次重開 Claude Code，請先讀這份文件以恢復專案背景。

## 專案概述

自動化下載台股財報數據，並產出標準化的季度損益表 Excel 模型，供分析師進行預測與比較。

## 資料來源

- **FinMind**：主要財報資料來源（台股）

## 目前完成的功能

| 檔案 | 說明 |
|------|------|
| `scripts/download_financials.py` | 輸入股票代號，透過 FinMind 下載財報並儲存為 CSV |
| `output/finmind/` | CSV 輸出目錄 |

## 下一步目標：季度損益表 Excel 模型

### 保留的財報項目（列）

- 營收
- 營業成本
- 毛利
- 營業費用
- 營業利益
- 稅前淨利
- 稅後淨利
- EPS

### 欄位結構（行）

| 欄類型 | 說明 |
|--------|------|
| 歷史季度（例如 2024Q1–2026Q1） | 從 FinMind 抓取的實際數字，匯入後不手動修改 |
| 2026Q2(F)、2026Q3(F)、2026Q4(F) | **可手動輸入的預測欄位**（分析師自行填寫） |
| 2026(F) 年度合計 | 用 Excel 公式加總四個季度 |

### 自動計算欄位（Excel 公式）

- **2026(F)**：全年預測合計（= 四季加總）
- **QoQ**：季對季成長率（= (本季 − 上季) / 上季）
- **YoY**：年對年成長率（= (本季 − 去年同季) / 去年同季）
- **毛利率**：= 毛利 / 營收
- **營業利益率**：= 營業利益 / 營收

### Excel 設計原則

- 預測欄位（2026Q2F–2026Q4F）以不同底色標示，提醒可手動修改
- 歷史數字欄位鎖定，避免誤覆蓋
- 所有比率欄位以百分比格式顯示

## 備註

- 目前階段不需要修改 `download_financials.py`，下一步重點在 Excel 產出邏輯
- Excel 產出建議使用 `openpyxl` 撰寫，以便控制格式、公式與欄位鎖定
